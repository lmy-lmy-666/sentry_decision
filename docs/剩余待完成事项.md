## 一、电控（STM32 固件）

### 1. 0xB6 → 0x0120 下行

ROS 端已通过：`sentry_decision` → `sentry/command` → `serial_driver` → `0xB6`

STM32 侧需要新增：

```
收到 0xB6 包 → 解包 → 拼成 0x0120 sentry_cmd → 发给裁判系统
```

当前仅 `stance_command` 被决策填充，其余字段预留。

### 2. 0x020D → ROS 上行

裁判系统下发 0x020D（哨兵自主决策信息同步）。STM32 需要新增自定义上行包转发给 ROS 端 `serial_driver`。

### 3. 双方基地血量/总伤害量 → ROS 上行

当前 STM32 只转发己方数据，缺少对方基地血量和总伤害量。用于后期判断领先/落后。

### 4. 0x020C → ROS 上行（可选）

空中威胁、双倍易伤标记。有则更好，暂无也不影响基础功能。
