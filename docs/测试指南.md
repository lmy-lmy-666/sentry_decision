## 一、单元测试（每次改代码必跑）

```bash
cd ~/Sentry26
source /opt/ros/jazzy/setup.bash
source install/setup.bash
colcon test --packages-select sentry_decision --cmake-args -DBUILD_TESTING=ON

# 或直接运行二进制
~/Sentry26/build/sentry_decision/fsm_test
```

当前覆盖 30 个场景：

| 类别 | 测试内容 |
|------|---------|
| 状态转移 | IDLE/PATROL/ATTACK_PUSH/RESUPPLY/RETREAT 进入和退出条件 |
| 优先级 | RETREAT > DEFEND(空中) > RESUPPLY > DEFEND(地面) > ATTACK_PUSH > PATROL |
| 边界 | hp=59/60 触发 critical，hp=120 退出 RETREAT，hp=150/400 RESUPPLY 边界 |
| 振荡防护 | 补给冷却防死循环，hysteresis 防抖动，stance 冷却+去重 |
| 碰撞/卡住 | nav_stuck 跳点，stale 数据回 IDLE |
| 弹药逻辑 | ammo=0 不管有无敌人都去补给，补给途中敌人不打断 |
| 战斗 | 敌人距离驱动 TRACK→ENGAGE，>8m 放弃，被击中进 EVADE |
| 数据过期 | EnemyInfo 1.0s 过期，referee stale 3s 进 IDLE |

## 三、ROS 环境模拟测试（不需要实机）

### 3.1 启动模拟数据源

**终端 1 - 裁判系统**：

```bash
source /opt/ros/jazzy/setup.bash

# 比赛进行中
ros2 topic pub -r 10 /referee/game_status rm_interfaces/msg/GameStatus \
  '{game_progress: 4, stage_remain_time: 300}'

# 机器人状态（hp=400, ammo=50, 没有被攻击）
ros2 topic pub -r 10 /referee/robot_status rm_interfaces/msg/RobotStatus \
  '{current_hp: 400, maximum_hp: 400, projectile_allowance_17mm: 50, shooter_17mm_1_barrel_heat: 0, is_hp_deduced: false, armor_id: 0, hp_deduction_reason: 0}'

# 己方全队血量（前哨站存活）
ros2 topic pub -r 10 /referee/all_robot_hp rm_interfaces/msg/GameRobotHP \
  '{ally_outpost_hp: 500, ally_base_hp: 1500}'
```

**终端 2 - 自瞄**：

```bash
source /opt/ros/jazzy/setup.bash

# 敌人 2m 处
ros2 topic pub -r 10 /auto_aim_target_pos std_msgs/msg/String \
  '{data: "2.0,0.0,1,3"}'
```

**终端 3 - 雷达**：

```bash
source /opt/ros/jazzy/setup.bash

# 敌方机器人在坐标 (5.0, 3.0)
ros2 topic pub -r 5 /radar/enemy_positions radar_msgs/msg/EnemyPosition \
  '{x: 5.0, y: 3.0, robot_type: 0}'
```

### 3.2 启动决策节点

**终端 4**：

```bash
source /opt/ros/jazzy/setup.bash
source ~/Sentry26/install/setup.bash

ros2 run sentry_decision sentry_decision_node --ros-args \
  -p profile_path:=~/Sentry26/src/sentry_decision/config/profiles/rmuc_blue.yaml \
  -p tick_frequency:=10.0
```

### 3.3 观察状态变化

```bash
# 终端 1 改为 hp=140（触发 RESUPPLY）
ros2 topic pub -r 10 /referee/robot_status rm_interfaces/msg/RobotStatus \
  '{current_hp: 140, maximum_hp: 400, projectile_allowance_17mm: 50}'

# 终端 1 改为 hp=40（触发 RETREAT）
ros2 topic pub -r 10 /referee/robot_status rm_interfaces/msg/RobotStatus \
  '{current_hp: 40, maximum_hp: 400, projectile_allowance_17mm: 50}'

# 关掉自瞄（模拟敌人消失）
# Ctrl+C 终端 2
```

### 3.4 模拟被攻击

```bash
# hp=400, 被击中装甲板 1 号
ros2 topic pub -r 10 /referee/robot_status rm_interfaces/msg/RobotStatus \
  '{current_hp: 400, maximum_hp: 400, projectile_allowance_17mm: 50, is_hp_deduced: true, armor_id: 1, hp_deduction_reason: 0}'

# 期望: state -> DEFEND/EVADE（切 OFFENSIVE 反击）
```

### 3.5 模拟空中威胁

```bash
# 雷达发布 type=4（空中）
ros2 topic pub -r 5 /radar/enemy_positions radar_msgs/msg/EnemyPosition \
  '{x: 10.0, y: 0.0, robot_type: 4}'

# 期望: state -> DEFEND/HARDEN → 15s → EVADE_AIR
```

## 四、实机测试 checklist

| 检查项 | 怎么测 | 期望 |
|--------|--------|------|
| 裁判数据正常 | `ros2 topic echo /referee/robot_status` | hp/ammo/heat 值在变 |
| 自瞄数据正常 | `ros2 topic echo auto_aim_target_pos` | data 格式 "x,y,valid,id" |
| 雷达数据正常 | `ros2 topic echo /radar/enemy_positions` | x/y 坐标，robot_type 0-5 |
| 决策启动 | `ros2 run sentry_decision ...` | 无 crash，输出 loaded profile |
| 状态切换 | 启动后查看日志 | 应在 PATROL 或 ATTACK_PUSH |
| RFID 识别 | 推车到补给区 | `ros2 topic echo /referee/rfid_status` 字段变 true |
| 导航目标 | 启动后 | 决策日志显示发 goal |
| 姿态指令 | 启动后 | `ros2 topic echo sentry/command` 有 stance 值 |
| 串口 0xB6 下行 | 电控侧确认 | STM32 收到 0xB6 并转发 0x0120 |

## 五、Bag 录制与回放

```bash
# 录制（完整话题集）
source /opt/ros/jazzy/setup.bash

ros2 bag record \
  /radar/enemy_positions \
  /referee/game_status \
  /referee/robot_status \
  /referee/all_robot_hp \
  /referee/rfid_status \
  /auto_aim_target_pos \
  /motion_manager/state \
  /motion_manager/motion_state \
  /odometry \
  -o test_bag_$(date +%Y%m%d_%H%M%S)

# 回放
ros2 bag play test_bag_YYYYMMDD_HHMMSS

# 另一终端启动决策查看状态变化
source ~/Sentry26/install/setup.bash
ros2 run sentry_decision sentry_decision_node --ros-args \
  -p profile_path:=~/Sentry26/src/sentry_decision/config/profiles/rmuc_blue.yaml
```

## 六、故障模拟

| 故障 | 模拟方式 | 期望行为 |
|------|---------|---------|
| 自瞄断连 | 停止自瞄 topic | 1.0s 后退出 DEFEND，回 PATROL |
| 裁判断连 | 停止裁判 topic | 3s 后进 IDLE，停止导航 |
| Nav2 宕机 | `pkill -f nav2` | fallback 模式，odom 判断到达 |
| 传感器闪断 | 快速开关 topic | 不崩溃，EnemyInfo 过期保护 |
| 导航卡住 | Nav2 发 STUCK 状态 | 路线跳下一个点 |
