# Sentry Decision 实车导航测试指南

没有裁判系统的前提下，用 mock 节点模拟裁判数据，在实车上验证巡逻、残血回家、补给的导航逻辑。

---

## 前提条件

- 实车上已部署 `sentry_decision_sample` 包
- Nav2 导航栈正常运行
- 里程计（`/odometry`）正常发布
- YAML 配置文件中的巡逻点和补给点坐标已对过实际场地

---

## 一、测试巡逻

### 步骤

```bash
# 终端 1：启动 mock 裁判（满血满弹，比赛进行中）
ros2 run sentry_decision_sample mock_referee.py \
  --ros-args -p hp:=400 -p ammo:=50 -p max_hp:=400 -p remain:=300

# 终端 2：启动决策节点（按你的 launch 文件启动）
ros2 launch sentry_decision_sample sentry_decision_sample_launch.py
```

### 预期行为

- 决策节点日志显示 `state -> PATROL`
- 机器人按 YAML 中 `patrol` 路线循环走动
- 前哨站血量 >0 时走 `patrol_aggressive`（如果有配置）
- 剩余时间 <60s 时走 `patrol_late`（如果有配置）
- 到达每个点停留 `dwell_s` 秒后去下一个

### 观察方式

```bash
# 看决策节点状态切换
ros2 topic echo /sentry_decision_sample/state  # 如果有的话，或者看终端日志

# 看导航目标
ros2 topic echo /goal_pose
```

## 二、测试残血回家（RETREAT）

### 步骤

```bash
# 先正常跑起来（同上一步骤 1、2）

# 终端 3：敲完装甲板后，手动把血量打到 40（< 60 临界值）
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 40, maximum_hp: 400, projectile_allowance_17mm: 50}" --once
```

### 预期行为

- 决策节点日志显示 `state -> RETREAT | reason: hp critical`
- 机器人停止巡逻，导航目标切换为补给点坐标
- 机器人向补给点移动
- 如果导航超时（30s），重发目标让 Nav2 重规划
- 总超时（60s）后放弃导航、原地等待

### 验证回血后退出 RETREAT

```bash
# 模拟血量恢复到 120 以上
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 150, maximum_hp: 400, projectile_allowance_17mm: 50}" --once
```

预期：`RETREAT → RESUPPLY`（因为 150 < 400 还需继续补给），继续往补给点走。

```bash
# 模拟血量回满
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 400, maximum_hp: 400, projectile_allowance_17mm: 50}" --once
```

预期：`RESUPPLY → PATROL`，恢复正常巡逻。

## 三、测试补给（RESUPPLY）

### 步骤

```bash
# 血量低于 150 但不低于 60
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 100, maximum_hp: 400, projectile_allowance_17mm: 50}" --once
```

### 预期行为

- `PATROL → RESUPPLY | reason: hp low`
- 机器人导航到补给点
- RFID 检测到踩上补给区 → 原地等待回血
- 回满后自动回 PATROL

### 弹药耗尽测试

```bash
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 400, maximum_hp: 400, projectile_allowance_17mm: 0}" --once
```

预期：血满但弹尽 → 仍进 RESUPPLY（`reason: ammo empty`）。

## 四、边界值测试

| 触发条件 | 命令中的 HP | 预期状态 | 原因 |
|----------|-------------|----------|------|
| 刚好临界不进 RETREAT | 60 | PATROL/RESUPPLY | hp < 60 才触发，=60 不触发 |
| 刚好临界进 RETREAT | 59 | RETREAT | < 60 触发 |
| 补给门槛不进 RESUPPLY | 150 | PATROL | hp < 150 才触发，=150 不触发 |
| 刚好进 RESUPPLY | 149 | RESUPPLY | < 150 触发 |
| RETREAT 滞后退出 | 100→120 | RETREAT→RESUPPLY | 退出需要 ≥120 |
| 没子弹但满血 | ammo=0 | RESUPPLY | ammo ≤ 1 触发 |

## 五、常用命令速查

```bash
# 满血满弹（正常巡逻）
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 400, maximum_hp: 400, projectile_allowance_17mm: 50}" --once

# 残血回家（紧急撤退）
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 40, maximum_hp: 400, projectile_allowance_17mm: 50}" --once

# 没子弹
ros2 topic pub /referee/robot_status rm_interfaces/msg/RobotStatus \
  "{current_hp: 400, maximum_hp: 400, projectile_allowance_17mm: 0}" --once

# 停止 mock
Ctrl-C 终端 1
```

## 六、故障排查

| 现象 | 可能原因 | 检查 |
|------|----------|------|
| 决策一直在 IDLE | mock 没跑或话题名不对 | `ros2 topic echo /referee/game_status` |
| 状态不切换 | 发的话题类型不对 | 检查 msg 类型 `ros2 interface show rm_interfaces/msg/RobotStatus` |
| 导航目标发了但机器人不动 | Nav2 没跑 | `ros2 action list \| grep navigate` |
| 巡逻路线不对 | YAML 配置坐标问题 | 检查 `patrol` 字段里的 x,y 值 |
| RFID 补给检测不触发 | RFID 话题字段名可能不对 | `ros2 interface show rm_interfaces/msg/RfidStatus` |
